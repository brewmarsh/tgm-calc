# User Guide

This document provides instructions for users of the TGM-Calc project.

## 1. Getting Started

To get started, you will need to create an account. You can do this by clicking the "Register" button on the home page. Once you have created an account, you can log in to the application.

## 2. Calculators

The application provides the following calculators:

*   **Troop Calculator:** This calculator helps you to determine the optimal troop composition to counter an opponent's army. To use this calculator, you will need to enter the number of bruisers, hitmen, and bikers in the opponent's army.
*   **Enforcer Calculator:** This calculator helps you to determine the best enforcers for a given situation. To use this calculator, you will need to enter your enforcers and the opponent's enforcers.
*   **Gear & Investment Calculator:** This calculator helps you to determine the total attack and defense boost from your gear and investments. To use this calculator, you will need to select your gear and enter the levels of your investments.
*   **Building Cost Calculator:** This calculator helps you to determine the investment required to get from level x to level y of a building. To use this calculator, you will need to select the building, enter the current level, and enter the target level.

## 3. User Profiles

You can save your troop and enforcer details to your profile for easy access. You can also customize your profile with an avatar.

## 4. Social Features

You can find and follow other users.

## 5. Screenshot Analysis

You can upload screenshots of your game data and have it automatically parsed and added to your profile. The screenshot analysis is done using the `pytesseract` library. If the extracted data is incorrect, you can correct it on the confirmation page. This will help to improve the accuracy of the OCR over time.
